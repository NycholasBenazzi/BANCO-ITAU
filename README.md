# Atividade Identidade Visual Itaú

Este repositório contém documentação e especificações sobre a **Identidade Visual Itaú**, incluindo variações de logotipos, paleta de cores, tipografia, escala de fontes e diretrizes de contraste.
--- 
## 🎨 Logotipos (Logos)

As variações de marcas/logotipos apresentadas na documentação incluem:
1. **Laranja Institucional**: Fundo laranja (#FF6200) com o texto "itaú" em branco.
2. **Azul Institucional**: Fundo azul (#1866BE) com o texto "Itaú" em amarelo/azul.
3. **Versão Clara / Clean**: Fundo branco com o texto "itaú" em laranja.
4. **Versão Escura / Dark**: Fundo preto (#0B0A0A) com o texto "Itaú" em branco.

  * SemiBold / Bold

## 👁️ Contraste e Acessibilidade

O guia contempla especificações para aplicação da tipografia em diferentes fundos, garantindo boa legibilidade:

1. **Fundo Claro (#F2F5F7)**: Texto em tom cinza/escuro para leitura confortável.
2. **Fundo Laranja (#FF6200)**: Tipografia em branco (#FFFFFF) para alto contraste.
3. **Fundo Escuro / Preto (#0B0A0A)**: Tipografia em branco (#FFFFFF) para legibilidade e destaque.
